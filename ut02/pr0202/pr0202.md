# PR0202 - Acceso a AWS S3 desde Python

## 1. Verificación de Identidad y Conexión Inicial
Copiamos desde el laboratorio en el apartado de **🛈 AWS Details** todo lo que viene en **AWS CLI** excepto la primera línea que es `[default]`.
```python
import boto3

aws_access_key_id="clave"
aws_secret_access_key="clave"
aws_session_token="clave"
region_name="us-east-1"
```

> Los tokens van cambiando cuando encendamos el laboratorio. Habría que copiar los tokens del laboratorio.

1. Obtener las credenciales:
```python
sts_client = boto3.client("sts",
                          region_name=REGION,
                          aws_access_key_id=MI_ACCESS_KEY,
                          aws_secret_access_key=MI_SECRET_KEY,
                          aws_session_token=MI_SESSION_TOKEN)
identidad = sts_client.get_caller_identity()
print(f"identidad: {identidad['Account']}")
print(f"Arn: {identidad['Arn']}")
```

2. Listar los buckets junto a la fecha de creación:
```python
s3_client = boto3.client("s3",
                          region_name=REGION,
                          aws_access_key_id=MI_ACCESS_KEY,
                          aws_secret_access_key=MI_SECRET_KEY,
                          aws_session_token=MI_SESSION_TOKEN)
respuesta = s3_client.list_buckets()
respuesta['Buckets']
for bucket in respuesta['Buckets']:
    print(bucket['Name'])
    print(bucket['CreationDate'])
    print("------------------------------")
```
